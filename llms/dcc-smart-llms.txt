# Smart DCC

> Smart DCC (the Data Communications Company) is the Ofgem-licensed monopoly that operates Britain's national smart metering communications network, connecting electricity and gas smart meters to energy suppliers, network operators and other authorised users over a single secure wide-area network. It is shared national infrastructure, not a retailer or a data marketplace, and it is regulated through the Smart Meter Communication Licence and governed by the Smart Energy Code.

Generated 2026-07-27 by API Evangelist (https://apievangelist.com) from the Smart DCC public surface. Smart DCC publishes no llms.txt of its own — https://www.smartdcc.co.uk/llms.txt returns 404.

## What is and is not available to a developer

- The production interface is DUIS (the DCC User Interface Specification), an XML web service reached over a dedicated DCC User Gateway Connection. The specification and its XML schema are published openly as Smart Energy Code subsidiary documents, but the gateway is closed to anyone who has not acceded to the Smart Energy Code and passed SMKI and User Entry Process Testing. There is no self-serve signup, no API key and no sandbox key.
- Britain mandated the infrastructure, not a consumer data right. There is no UK equivalent of the Australian Consumer Data Right for energy and no Green Button regulation, so Smart DCC operates no consumer data-portability API.
- Network statistics and performance are published as rendered web pages with no documented open-data API or bulk download.
- The only self-serve, machine-readable API contract Smart DCC publishes anywhere is the OpenAPI for the open-source DCC Boxed DUIS signing and validation tool, which runs locally.

## APIs

- [DCC Boxed DUIS Signing Tool API](https://github.com/SmartDCCInnovation/dccboxed-signing-tool): Two operations — POST /sign adds an XML digital signature to a Base64-encoded unsigned DUIS request (optional preserveCounter flag), POST /verify validates the signature on a DUIS response and strips it. Self-hosted; default http://localhost:8080. No authentication. Ships the ZAZ1 test SMKI certificates and performs DUIS XSD validation.
